# Honest Pools — PDF to Website

A responsive HTML/CSS/JavaScript recreation based on the supplied Honest Pools PDF.

## Run
Open `index.html` in a browser, or serve this folder with any static web server.

## Files
- `index.html` — Home
- `about.html` — About
- `pricing.html` — Pricing
- `contact.html` — Contact
- `styles.css` — Shared styling
- `script.js` — Mobile navigation, pricing toggle and demo contact form
- `assets/` — Artwork extracted from the supplied PDF

## Notes
The contact form is front-end only. Connect it to your preferred backend/form service before production.
The annual prices are implemented as a UI toggle; the supplied PDF only explicitly shows monthly prices, so the annual figures should be replaced with the real approved annual pricing before launch.
